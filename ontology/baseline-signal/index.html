Baseline Signal

A baseline signal is a low or non-prominent blood ketone reading described without a strong contextual interpretation. It is the reference point the other classes are read against, not a statement that a person is fine.

Governing Rule (KSO)

Use for educational explanations of normal or low ketone presence when no strong contextual interpretation is being made.

What This Class Is

The Baseline Signal is the Ketonemia Signal Ontology class for a low or non-prominent ketone signal — the kind of reading described when no strong contextual interpretation is being made. It is the anchor of the ontology: every other class describes how a signal moves away from baseline under a specific context.

Baseline is a reference frame, not a clearance. Describing a signal as baseline says the reading is low or unremarkable in general educational terms; it does not evaluate an individual, and it does not mean a reading is appropriate for any particular person’s situation.

What It Is Not

The baseline frame is often confused with a “normal result.” The distinction matters:

  • Not a Nutritional or Fasting Signal. Those describe a signal that has moved up for a documented dietary or fasting reason. Baseline describes a low signal with no such context applied.
  • Not a clearance. A baseline description is educational; it is not a statement that a reader is healthy, safe, or free of a condition.

Relationship to the KSS Standard

In the Ketonemia State Standard (KSS), the baseline frame corresponds most closely to K0 — Baseline (a low or non-prominent ketone signal), and shades toward K1 — Low Presence as a detectable signal appears that still requires context before meaning is assigned. These are reference labels, not clinical thresholds. See the Signal Map.

Boundary Language

This class describes a reference frame, not a person. A baseline description does not tell any individual that their reading is normal, safe, or unremarkable for them. If you have questions about your own readings, see the clinical boundary and consult a qualified healthcare professional.

Audience Notes

Public readers A baseline description is a starting point for understanding the vocabulary — not a statement about your own health. The same low reading can mean different things in different situations.
