DKA Concern Boundary

The DKA concern boundary is not a diagnosis. It is a boundary class used when ketone information belongs in a clinical concern frame — it links to clinical care guidance and cited sources, and it never determines that a person has, or does not have, diabetic ketoacidosis.

Governing Rule (KSO)

Not a diagnosis. A boundary class used when ketone information belongs in a clinical concern frame. Must link to clinical care guidance and cited sources.

What This Class Is

The DKA Concern Boundary is a boundary class in the ontology, not a signal-context class and not a diagnosis. It is the frame used when ketone information belongs in a clinical concern setting — for example, ketones discussed alongside diabetes, illness, or medication risk — and its job is to route that information toward clinical care guidance and cited sources.

Diabetic ketoacidosis is a serious clinical syndrome defined by a broader clinical picture, not by a ketone number alone. This class names the boundary at which reference language stops and clinical assessment begins; it does not cross it.

What It Is Not

This class is defined by what it refuses to be:

  • Not a diagnosis. DKA requires clinical assessment — blood pH, the full clinical picture, and professional judgment — never a ketone value alone.
  • Not the Emergency Referral Boundary. This class marks a clinical-concern frame; the Emergency Referral Boundary is the separate, higher class for language pointing toward urgent evaluation where cited guidance supports it.

Relationship to the KSS Standard

This class aligns with the KSS K4 — Clinical Concern Boundary: a concern zone where cited guidance may recommend professional medical contact or assessment. K4 is a reference boundary label, not a diagnostic threshold and not a determination about any person. See the Signal Map and Ketonemia vs. Ketoacidosis.

Boundary Language

A boundary, not a diagnosis. The DKA concern boundary marks where ketone information belongs with a qualified healthcare professional. It does not diagnose or rule out diabetic ketoacidosis, does not assign urgency, and does not ask you to self-assess. If you are concerned about ketones in the context of diabetes or illness — particularly with symptoms — contact a healthcare professional or seek care. See the clinical boundary.

Audience Notes
