How This Engine Is Governed

The engine is a deterministic lookup, not a model and not a calculator. Every output follows the same nine-field template defined in the Classification Protocol: context classification, KSO class, KSS language, measurement note, boundary statement, allowed language, prohibited inference, canonical references, and source requirements. The boundary statement and prohibited-inference language never soften, regardless of which context is selected — only the surrounding explanation adapts to the chosen audience.

The rules themselves are published and reviewable at /data/classification-rules.json, and the reasoning they encode is documented in full in the Reference Pack and the site’s governance layer.
