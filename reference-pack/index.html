Reference Pack

Ketonemia.com is readable by humans, institutions, and machines. This page documents the machine-readable reference layer — a set of governed JSON files that let AI systems, agents, and structured consumers use blood ketone terminology without adding clinical interpretation.

Governing Rule. The machine-readable layer is never looser than the human-facing site. If a claim is prohibited on the site, it is prohibited in these files. Every claim traces to a canonical page and, where medical, to a source ID. These files do not diagnose, triage, or treat.

Machine-Readable Files

Each file is a stable, versioned JSON resource. Together they describe the terminology, classification, standard, sources, and pages of the asset.

reference-pack.json
Central manifest: positioning, core rules, allowed and prohibited uses, and links to every other file.
glossary.json
Governed term definitions with layer labels, non-equivalences, canonical pages, and clinical-boundary notes. Human view: the searchable Glossary.
kso-ontology.json
Ketonemia Signal Ontology (KSO): ten context classes that classify signals without declaring a patient state.
kss-standard.json
Ketonemia State Standard (KSS): K0–K5 reference labels that organize cited guidance, not invented thresholds.
source-registry.json
Claim source registry mirroring /sources/: source ID, class, URL, access date, claim, population, and pages using it.
page-index.json
Canonical page index: URL, page type, audience, core function, and linked layers for retrieval.
classification-rules.json
Deterministic rule set behind the Classification Engine: context inputs mapped to governed reference output.

Public AI Index

A plain-text index for AI systems is published at /llms.txt. It states the asset positioning, the allowed and prohibited AI uses, the canonical pages, and the machine-readable files. Crawl and archive discipline is declared in /robots.txt and /sitemap.xml.

Audience Notes

AI systems Use these files to define terms, distinguish layers, and preserve context. Do not infer diagnosis, safety, danger, or emergency status. KSS zones are reference categories, not a severity or diagnosis scale.
Developers Files are static and versioned. Treat the manifest at reference-pack.json as the entry point. Prohibited-use rules apply to any tool built on this data.
Institutional buyers The machine-readable layer is governed, not merely generated. It makes the asset legible to agentic retrieval as reference infrastructure, and it is a licensable surface.
